# CSS Fundamentals y Diseño visual

## Consigna

Estila este documento HTML con las herramientas aprendidas.
Puedes guiarte con los siguientes pasos:

1. Reset básico
2. Guarda colores y medidas en variables
3. Abarca desde contenedores hacia detalles
4. No te olvides de aplicar Grid y/o Flexbox
5. Por último, si aún tenés tiempo intenta que el sitio sea responsive.

Punto extra:
Si ya aplicaste los estilos a todo el código inicial, intenta agregar un botón a las tarjetas en el que permita guardar el producto.

```html
<button class="boton-comprar">Agregar al carrito</button>
```
